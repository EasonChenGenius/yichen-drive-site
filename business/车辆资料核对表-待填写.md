### 每个字段从哪里来

| 字段 | 依据（不能猜） |
|---|---|
| `year` 年款 | 对应年款配置资料；首次注册日期单独核对，不能直接当作车型年款 |
| `trim` 版本 | 实车尾标 + 配置单（例：ES陆尊 653T 舒适型） |
| `seats` 核定座位 | **行驶证「核定载客人数」**，不是"最多能坐几个" |
| `bags` 行李件数 | 满员状态下实测能放几只 24 寸箱（建议拍照存档） |
| `drive` 驱动 | 配置单 / 尾标（xDrive、4MATIC 等） |
| `energy` 能源 | 汽油 / 柴油 / 纯电 / 插混 |
| `transmission` 变速箱 | 配置单 |
| `carplay` | 实车车机实测，`true` / `false` |
| `price` 日租价 | 你的对外报价（人民币/天） |
| `deposit` 押金 | 取车时收取的押金金额 |

## 二、合同与计费规则（同一文件的 `RENTAL_TERMS`）

| 字段 | 说明 | 状态 |
|---|---|---|
| `minRentalDays` | 最短租期（天） | ❌ |
| `minDriverAge` | 驾驶员最小年龄 | ❌ |
| `minLicenceYears` | 驾照最短持证年限 | ❌ |
| `deposit` | 统一押金（单车押金优先） | ❌ |
| `freeKmPerDay` | 每日免费里程（km） | ❌ |
| `excessKmPrice` | 超公里单价（元/km） | ❌ |
