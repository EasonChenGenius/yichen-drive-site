## 二、云服务器怎么选

照这个规格挑，不要买更低的：

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| CPU / 内存 | **2 核 2GB**（能上 4GB 更好） | 跑 Flask + nginx 够用 |
| 磁盘 | **50GB 以上** | 你的图片就有 117MB，还要留数据库和备份空间 |
| 带宽 | **4Mbps 以上** | 图片多，带宽太小程序加载慢 |
| 系统 | **Ubuntu 22.04 或 24.04** | 我的部署脚本基于 Ubuntu，别选 Windows 或 CentOS |
| 地区 | **中国大陆**（成都 / 广州 / 上海） | 客户主要在四川；境外服务器访问慢且合规不同 |

⚠️ **看清楚「续费价」，不要只看首年活动价。** 很多套餐首年 99 元、续费五六百。按「续费之后仍在 1000 元/年预算内」来选。具体价格以你登录账号后看到的官方报价为准，我不替你承诺活动价。

官方入口：
- 腾讯云轻量应用服务器：https://cloud.tencent.com/product/lighthouse
- 阿里云轻量应用服务器：https://www.aliyun.com/product/swas

## 三、域名怎么选

- 后缀优先 `.com`，其次 `.cn`
- 简短、好念、跟品牌相关，例如：`yichendrive.com`、`ycdrive.cn`
- **先查能不能注册**，再决定
- 域名的**实名认证主体必须和后面 ICP 备案主体一致**（都是你的公司/营业执照）

⚠️ `.cn` 域名和大陆服务器都要求实名 + 备案，这是规定，绕不开。

---

## 四、购买顺序（照着做）

1. **注册云账号** → 做**企业实名认证**（用你的营业执照，个人实名备案主体会和营业执照不一致）
2. **买域名** → 完成**域名实名认证**
3. **买服务器** → 选上面那套配置，Ubuntu 系统
4. **提交 ICP 备案** → 免费，通常 **10–20 个工作日**
5. **备案通过** → 把服务器信息给我，我开始部署

备案和第 4 步不能跳过：**大陆服务器绑定域名对外开放前，法律要求完成 ICP 备案。**

---

## 五、备案大概要准备什么

- 营业执照
- 网站负责人身份证正反面
- 域名证书（买完域名后在控制台下载）
- 负责人手机号、邮箱
- 幕布照片（云服务商会给你拍照指引，在 App 里完成）

这些都在云服务商的备案系统里提交，**不用发给我**。

| 给我 | 用途 |
| --- | --- |
| 服务器**公网 IP** | 配置 nginx 和连接 |

## 九、一个常见误解

**买了服务器 ≠ 网站立刻能用**。备案没下来之前，域名不能对外访问。这段时间你可以先在本地继续用 http://127.0.0.1:8766/ 看效果、填车辆资料，两件事不冲突。
