# 实车外观与内饰模型接入

## 当前状态

十一款目录车型均未有已核验的精确模型。模型开关保持关闭；旧考斯特结构原型不作实车展示。GL8 当前版本不能用陆上公务舱照片替代陆尊。上传单张照片不能确定背面、车底或未拍摄内饰。

## 建模资料

每款车型需要明确年款、版本、实际颜色和改装情况。外观至少包含前后左右、45°前后、灯组、格栅、轮毂及车身尺寸资料；内饰包含仪表台、方向盘、前排、中后各排、门饰板、顶棚、座椅与地板。座椅数量和布局以实车资料为准。已有 CAD、扫描网格或带材质的 Blender 工程可直接修整。

Lux3D / to3D 可用于辅助生成有照片依据的部分；未见细节不视为已还原。生成后在 Blender 中校准比例、轮廓、灯组和各部件，修整拓扑、UV、法线与材质，再对照每个实拍角度核验。原工程与原始照片保留。

## 导出与网页约定

- 外观、内饰使用 GLB，内嵌贴图。保留需要真实开关门等动画的独立节点；当前网页只提供环绕与环视。
- 导出为米、Y 轴向上，车头朝 +X。内外模型采用相同坐标原点、比例和轴向；网页以外观包围体居中，仅对两份模型应用同一平移。
- PBR 车漆清漆层、玻璃、金属、橡胶和座舱材质分别保留，避免把反射高光烘焙成不会随视角变化的贴图。源材质参数不会被查看器统一替换。
- `vehicle-configs.js` 的 `modelVerified` 与 `modelPath` 只在准确外观核验后填写；内饰另填 `interiorModelVerified`、`interiorModelPath`、`interiorViews`。
- 每个内饰视点 `position` / `target` 为导出 GLB 的真实坐标，来源于在 Blender 内实际摆放的相机。二者不能相同；可提供 `label`、`labelEn`、35–90 度的 `fov`。不得用虚构坐标或透明车壳代替不存在的内饰。
- 未配内饰模型时，内饰入口关闭；模型错误可重试，不生成替代车辆。

## 查看器行为

外观由 OrbitControls 支持完整水平环绕、缩放和前/侧/后视角。内饰保持相机在确认视点，只调整朝向与视场，水平可环视 360°；可切换已确认的前排/后排等真实视点。默认不接管手势；点击“启用查看”后进入交互，结束查看或 Escape 恢复页面滚动。自动旋转需主动开启，减少动态效果时禁用。

当前仅完成接入代码与程序检查；准确模型、贴图质感和内饰视点仍待资料与模型完成后实际验收。
