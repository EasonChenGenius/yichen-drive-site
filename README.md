# YICHEN Drive · 成都 / 四川版

## 启动网站与账户服务

macOS 双击 `启动网站.command`，保持终端窗口开启，再手动访问 **http://127.0.0.1:8766/**。

也可以在本目录运行：

```bash
python3 server.py --port 8766
```

需安装 Python 3.10 或更高版本，无需安装其他 Python 包。运行后会创建 `data/accounts.sqlite3`。此目录用于账户数据，不属于静态网站公开目录。复制整个项目到新电脑不会自动迁移已注册账户，需要一并备份数据目录。服务未运行时，直接打开 `dist/index.html` 仍可浏览、选地点和模拟预订；登录注册会显示启动提示。

## 高德地图最后的配置

地图接口已接入，但此包不包含第三方账户 Key。申请 Key 需要使用站点所有者的高德开放平台账户。

1. 在 [高德开放平台](https://console.amap.com/dev/key/app) 创建应用，添加 **Web 端（JS API）** Key；同时取得安全密钥 `securityJsCode`，并配置你实际使用的网站域名白名单。
2. 将 `.env.example` 复制为 `.env`，填入：

```dotenv
AMAP_JS_KEY=你的Web端JS_API_Key
AMAP_SECURITY_CODE=你的securityJsCode
```

3. 重新启动 `server.py` 并刷新页面。浏览器可以按成都范围搜索高德地点、获取当前位置及具体地址、在地图中选择已列出的地标；定位或地图标记仍需明确确认后才会搜索车辆。

安全密钥只在服务端读取，通过 `/_AMapService` 代理追加，不会返回给浏览器。地图 Key 作为公开客户端标识由 `/api/config` 下发。部署正式网站时请使用 HTTPS，并在 `.env` 设置准确的 `YICHEN_PUBLIC_ORIGIN=https://你的域名`，以启用 Secure Cookie 和来源检查。浏览器需允许定位权限，高德服务也可能受网络与 Key 配额影响。未配置或加载失败时仍可手动选成都主要地点，不会伪造定位或地图数据。

官方参考：[JS API 安全密钥与代理](https://lbs.amap.com/api/javascript-api-v2/guide/abc/prepare)、[定位服务](https://lbs.amap.com/api/javascript-api-v2/guide/services/geolocation)、[输入提示](https://lbs.amap.com/api/javascript-api-v2/guide/services/auto-complete)。

## 正式登录注册如何上线

当前邮箱密码账户已经能在本地服务里注册、登录和保存演示订单，账户数据不依赖浏览器本地假登录。线上版本可以继续用此方式，或改为手机号验证码：由后端调用你的短信服务账号，验证成功后创建账户或建立登录会话。短信服务费用、签名与模板需由你名下的服务账户配置，前端不能自行发送正式验证码。

公开上线前需要部署 HTTPS 后端与持久数据库、补齐邮箱验证 / 找回密码或正式短信验证码、账户条款、监控与数据备份。本包的账户服务按本地开发用途提供，不是已经发布的线上身份系统。预订的真实库存校验与真实支付还需分别接入正式业务系统。
